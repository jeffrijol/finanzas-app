1. Middleware usando SUPABASE_ANON_KEY como fallback
typescript

// ❌ RIESGO DE SEGURIDAD GRAVE
// packages/backend/src/middleware/auth.ts
const supabaseAdmin = createClient(
  process.env.SUPABASE_URL!,
  process.env.SUPABASE_SERVICE_ROLE_KEY || process.env.SUPABASE_ANON_KEY // ← PELIGROSO
);

Problema: La ANON_KEY tiene permisos limitados y puede no verificar correctamente tokens en todos los casos. Siempre debe fallar explícitamente si falta la SERVICE_ROLE_KEY.

Solución:
typescript

// ✅ CORRECTO - Falla explícitamente
const supabaseServiceKey = process.env.SUPABASE_SERVICE_ROLE_KEY;
if (!supabaseServiceKey) {
  throw new Error('SUPABASE_SERVICE_ROLE_KEY no configurada');
}

const supabaseAdmin = createClient(
  process.env.SUPABASE_URL!,
  supabaseServiceKey
);
